# Rocket Práctica

Juego 3D en el navegador para practicar mecánicas estilo Rocket League: carro tipo Fennec, boost, saltos, flips, paredes, modos de entrenamiento y partido contra un bot.

## Cómo jugar

Abre `index.html` desde un servidor local (los modelos 3D no cargan con doble clic):

```
python -m http.server 8765
```

y entra a http://localhost:8765. Los controles están en el menú **Controles** del juego.
